# 静态红绿灯匹配回归

在 macOS 的 Swift 环境运行 `bash ios/tests/traffic-lights/run.sh`。
测试直接编译生产 `RouteGeometry.swift` 和 `RouteTrafficLights.swift`，无 SDK、网络或真机依赖。

覆盖原始坐标保留、同路名和 25 米驶入方向、平行路、交叉路、回环、桥/隧道/高架/匝道/未知 Link、缺失道路名、未查询与查询无灯的区别，以及 300 米距离包和失效清除。

数据只来自 SDK `routeTrafficLights` 或 `isHadTrafficLights` 标记 Link 的末坐标。网页路线给出的总数仅作总数，不生成坐标，不发送实时灯态或倒计时。静默算路不会启动驾车导航，也不会更换用户选定的摩托路线。

高度限制：网页摩托路线没有高度/道路层级。匹配采用 2D 坐标、同路名、方向及驶入段，并拒绝附近的歧义通过、明确桥/隧道/高架/匝道和未知 SDK Link。它不能证明完全重叠、同名且未标明层级的道路在同一层，也不保证路口完整。未知或未核对的路口不计为已核对灯位。
