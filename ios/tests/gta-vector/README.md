# GTA vector protocol parity

`bash ios/tests/gta-vector/run.sh` runs the production Swift parser, codec, cache
and download orchestration against an injected local tile service. It requires
Swift 5.7+ with Foundation; Xcode or an iPhone is not needed for these tests.

The fixture `14_13484_6201.pbf` is public OpenFreeMap / OpenStreetMap map data,
retained from the Android aa.4 map tests. Data © OpenStreetMap contributors,
[ODbL](https://www.openstreetmap.org/copyright); tile service
[OpenFreeMap](https://openfreemap.org/). It contains all five road classes and real
POIs. No user route, API key, device identifier or personal location trace is in
this fixture.

`android-aa4-type1.bin` was generated by the existing production Android
`GtaVectorCodec` and `GtaVectorTest` at frame 77, centre (0,0), using the GCJ-02
coordinate of this tile's centre as the frame reference. The test requires the
Swift encoder to match that packet byte for byte, checks malformed input and
overflow limits, and verifies complete cached operation and corrupt-tile repair.

Fixture SHA-256:

- `14_13484_6201.pbf`: `8d53a75158270f3549c5306ef4e7a8a53c1216f8b1b9da41f5d81fe7ca8b481b`
- `android-aa4-type1.bin`: `945955e93e1277211574b54ddd804ec6e0fe8f593a059c78391096e6e12da197`

Tile/cache failures never substitute an empty road network. The caller retains
its current map until a complete replacement packet has been received and ACKed.
