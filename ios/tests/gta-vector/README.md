# GTA vector protocol parity

`bash ios/tests/gta-vector/run.sh` runs the production Swift parser, codec, cache
and download orchestration against an injected local tile service. It requires
Swift 5.7+ with Foundation; Xcode or an iPhone is not needed for these tests.

The fixture `14_13484_6201.pbf` is public OpenFreeMap / OpenStreetMap map data,
retained from the Android aa.4 map tests. Data © OpenStreetMap contributors,
[ODbL](https://www.openstreetmap.org/copyright); tile service
[OpenFreeMap](https://openfreemap.org/). It contains all five road classes and real
POIs. No user route, API key, device identifier or personal location trace is in
this fixture.

`android-gta-poi28-type1.bin` was generated by the production Android
`GtaVectorCodec` and `GtaVectorTest` at frame 77, centre (0,0), using the GCJ-02
coordinate of this tile's centre as the frame reference. The Swift encoder must
match it byte for byte. The old `android-aa17-type1.bin` remains the reference for
unchanged road and water geometry.

The suites cover 50 precise class/subclass pairs across wire classes 20 through
47, and 40 unsupported or misleading pairs. Tagged synthetic points test the
wire path without claiming that every category exists in the geographic fixture.
Airports may also come from real point geometry in `aerodrome_label`; lines in
that layer do not create airport icons. No Overpass query or extra data source is
used. The geographic fixture gains fire, bus, parking, harbor, lodging and office
points; absent helipads and race venues are not invented.

Malformed-input checks, overflow limits, cached operation and corrupt-tile repair
still run. The `ofm-gta-vector-v5-poi28` rendered-content key isolates old GTA
packets while retaining raw PBF tiles and other map-style caches.

On this Windows workspace, compile the production Kotlin/Java codec and run its
tests with `android/tests/run-gta-poi28.ps1` in `MotoNav-Android-aa21`. The script
uses the existing JDK and cached Kotlin compiler and writes the Android reference
packet to `output/gta-poi28-tests/android`.

its current map until a complete replacement packet has been received and ACKed.
