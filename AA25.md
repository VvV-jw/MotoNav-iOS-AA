# AA25

The iOS app opens on the round-screen device page. The layout follows the supplied
light device card and dark connection sheet: a real product image, accessory name,
power, display/settings entry points, connection management and location status.
Maps, route planning, cruise, offline maintenance, audio, media buttons, Key
settings and notification controls remain reachable.

`RoundDeviceState` receives the existing `V,percent,charging,usb,millivolts`
accessory telemetry. Missing power stays unknown and reconnect clears old values.
Names come from CoreBluetooth callbacks; no sample suffix is shipped as identity.
Stopping search cancels the actual pending connection and automatic retry.

Phone appearance follows the system by default, with explicit light/dark choices.
The requested floating navigation theme is ID 12, using the established TYPE 1
OpenFreeMap vector path and its 2400 m half extent. It has a separate cache content
identity and retains existing offline preparation, receipt and recovery behavior.
The AA25 appearance migration runs once, preserving the former theme and all keys.

The product asset is derived from the repository's actual `navigation.jpg`
hardware photograph. Background and USB cable were removed with image generation;
it is a product illustration, not a live screen mirror.

Release: 0.15.25 / build 25. Base bundle and extension identifiers are unchanged.
