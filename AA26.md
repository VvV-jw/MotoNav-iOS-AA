# AA26

Floating navigation (theme 12) sends road instructions at 20 pt system Medium
inside a fixed 24 px cell, at most 312 px wide. Long instructions use an ellipsis
at the same font size. The existing packed 4 bit coverage and bitmap slot 0 are
unchanged, so the round screen can display the pixels without another rescale.

Native SDK and independent navigation use the same renderer. The BLE connection
retains the source instruction and rerenders it when switching into or out of
theme 12; clearing navigation also clears this source cache. Other themes and
music/weather/lyrics retain their existing rendering.

The focused simulator test compiles the production UIKit renderer, checks
dimensions, coverage, prefix stability and legacy-theme selection, and exports
lossless PNGs plus raw packed coverage with exact source commit/hash provenance.
It does not claim physical display, BLE, or live map SDK validation.

Release: 0.15.26 / build 26. Bundle identifiers, settings and keys are unchanged.
Delivery is an unsigned IPA for the existing SideStore account; no phone install.
